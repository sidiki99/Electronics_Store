
# Electronics Store

## Overview

Electronics Store is a .NET C# application developed in Visual Studio for managing electronic products and store inventory. The system provides an easy way to add, update, delete, and view product information.

## Features

* Add new electronic products
* View all products
* Update product details
* Delete products
* Search for products
* Manage inventory records

## Technologies Used

* C#
* .NET
* Visual Studio
* SQL Server 

## Requirements

* Visual Studio 2022 
* .NET SDK
* SQL Server (if the project uses a database)

## Installation

1. New created repository:


2. Open the solution (.sln) file in Visual Studio.

3. Restore NuGet packages.

4. Build the project:

   * Build → Build Solution

5. Run the application:

   * Press F5 or click Start.

## Project Structure

* Models – Data classes
* Forms/Pages – User Interface
* Services – Business logic
* Database – Data access and storage
